- 3종 투명 프레임·상태·지연, 걱정/수면의 같은 캐릭터 기본 모습 확인.
- 폴더 밖/절대 경로·잘못된 형식·누락/손상·빈 프레임·ID/alias 오류 거부.
- 64프레임·파일/픽셀/메모리 한도·잘못된 지연·범위 밖/거대 좌표·과도한 JSON 중첩/수치 거부.
- 전환 시 집중 세션·진행 상태·위치·임시 크기·직접 숨김 보존. 기본 이름 전환과 사용자 별명 보존.
- 프레임별 타이머 간격·속도 반영, 준비/저장 실패 시 이전 그림과 선택 유지.

- 프리셋 입력·원형/막대형 전환·우클릭 시작/일시정지·진행 중 빠른 시작 비활성화.

스키마 6을 유지하며 설정 필드만 확장했습니다. 데이터 초기화·사용자 원본 삭제·네트워크 기능 추가는 없습니다. 자동 검사가 모든 오류를 찾는 보장은 아닙니다.

## Windows Qt 자체 실행

`tools/native_smoke.py`를 `QT_QPA_PLATFORM=windows`로 실행했습니다. 전용 `.qa/native-smoke-characters/<UUID>` DB와 `.qa/native-smoke-characters.json`을 사용했습니다.

- 펫/트레이/관리창·계획·캘린더·집중/통계·브리핑·숨김/크기 복원 확인.
- 채팅 변경 전 비저장·확인 저장·타이머 제어·3종 말투·우사기 형식/클릭 반응 확인.
- 실제 우사기 그림·원형 타이머·캐릭터 선택 중 집중 세션 유지와 캐릭터 화면 확인.
- 종료 뒤 paused 체크포인트·설정 보존·잠금 해제·서비스 타이머 정지 확인.

Qt API로 앱을 조작한 검사이며 실제 OS 마우스/키보드·트레이·알림 클릭을 대신하지 않습니다.

## 화면과 빌드

`tools/render_preview.py`는 전용 QA DB에서 앱 위젯만 렌더링합니다. 기존 페이지와 3종 채팅, 실제 3종 선택·집중 미리보기·첫 선택·원형 타이머, 어두운 720×560 캐릭터 화면을 점검했습니다. 사용자 데이터나 다른 앱을 캡처하지 않았습니다.

PyInstaller **0.5.2 one-folder 빌드**와 포함 파일을 확인했습니다. 모루·아이콘·고정 3종의 각 5파일(manifest/atlas/focus 3장)·Qt Windows 플러그인·tzdata Asia/Seoul과 선택 모듈을 포함합니다. 작업 원본·DB·로그·QA·키 파일은 제외합니다.

EXE 자체 실행은 미검증입니다. 이전 Windows 앱 제어 정책 거부를 우회하지 않았습니다. 확인된 실행 경로는 `run_windows.bat`의 Python/PySide6 소스 실행입니다.
