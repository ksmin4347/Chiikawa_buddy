# Windows에서 처음 사용하기

## 이 PC에서

1. 프로젝트 폴더의 `run_windows.bat`을 더블클릭합니다.
2. 화면 오른쪽 아래의 초록색 새싹 캐릭터 모루를 찾습니다.
3. 한 번 클릭하면 인사하고, 더블클릭하면 홈·설정 관리창이 열립니다.
4. 설정에서 이름과 크기를 바꿉니다. 변경사항은 자동 저장됩니다.
5. 캐릭터를 드래그해 편한 자리에 둡니다.

개발 환경은 이 작업에서 `.venv`에 준비했습니다. 이 폴더는 다른 PC로 복사해 사용하는 배포 환경이 아닙니다.

## Python이 없는 PC에서

`dist\DesktopBuddy` 폴더 전체를 복사한 뒤 그 안의 `DesktopBuddy.exe`를 더블클릭합니다. `_internal` 폴더를 빼거나 EXE만 복사하면 실행되지 않습니다. 첫 실행에도 API 키는 필요하지 않습니다.

현재 EXE는 초기 검증용입니다. 이 PC에서는 Windows 앱 제어 정책이 실행을 차단하여 EXE 검증을 완료하지 못했습니다. 소스 실행은 `run_windows.bat`을 사용하세요. 다른 PC와 Windows 10에서의 최종 호환성 검증은 아직 진행하지 않았습니다.

## 개발 소스를 새 PC에서 실행하기

1. Python 3.12 이상을 설치합니다.
2. `setup_windows.bat`을 더블클릭하고 준비 완료를 기다립니다. 이 단계는 인터넷을 사용합니다.
3. `run_windows.bat`을 더블클릭합니다. 앱을 사용할 때에는 인터넷 연결이 필요하지 않습니다.

준비나 실행에 실패하면 창이 유지됩니다. 오류 문구를 복사해 전달하면 해당 오류부터 수정할 수 있습니다. 관리자 권한 실행이나 Windows 설정 변경은 필요하지 않습니다.

## 숨기기와 종료의 차이

- **관리창 닫기**: 캐릭터와 트레이는 계속 실행합니다.
- **캐릭터 숨기기**: 캐릭터와 인사 말풍선만 숨깁니다. 숨긴 동안 애니메이션도 멈춥니다.
- **프로그램 종료**: 캐릭터·트레이를 없애고 프로세스를 끝냅니다.

캐릭터가 안 보이면 작업표시줄 오른쪽 트레이를 확인하거나 앱을 한 번 더 실행합니다. 중복 실행은 만들지 않고 기존 앱의 캐릭터와 관리창을 불러옵니다. 트레이 메뉴의 '캐릭터를 오른쪽 아래로 이동'으로 위치도 복구할 수 있습니다.

## 저장된 설정

파일 탐색기의 주소창에 `%LOCALAPPDATA%\DesktopBuddy`를 입력하면 저장 폴더를 볼 수 있습니다. 설정과 위치는 `buddy.db`, 간단한 오류 기록은 `logs\app.log`에 있습니다. 로그에는 설정 내용이나 API 키를 기록하지 않습니다.

앱이 종료된 상태에서 폴더 전체를 다른 위치로 복사하면 수동 보관할 수 있습니다. 백업/복원 버튼은 아직 없습니다. 오류가 있어도 DB를 삭제하지 마세요. 원본을 보관한 채 오류 기록과 함께 문의해 주세요.

## 지금 직접 확인할 내용

- 클릭과 더블클릭 반응이 동시에 나오지 않는지.
- 드래그 후 종료·재실행하면 같은 위치인지.
- 트레이의 숨기기·복원·종료가 작동하는지.
- 투명한 모서리 뒤에 있는 다른 창을 클릭할 수 있는지.
- 사용 중인 모니터와 배율에서 캐릭터와 글자가 자연스럽게 보이는지.
