- 기존 설정·저장·계획/반복/알림·캐릭터·집중/통계·생활/브리핑·프로세스 종료·오프라인 채팅 회귀 유지.
- 3종 말투에서 인사·공부 의욕·시험 성공·계획 미완료·응원·감사와 불필요한 DB/타이머 실행 없음.
- 상황별 응답 변화, 선택하지 않은 감탄사 혼입 방지, 우사기 감탄사 + (내용) 형식·반말.
- 날짜·시간·숫자·제목·괄호·Windows 경로·코드 블록·명령어·수식의 원문 유지.
- 일정 추가 전 비저장/확인 후 실제 저장, 타이머 25분/중지 확인과 실제 상태, 중복 확인 1회.
- 대화 캐릭터 선택 저장/복원, 전환 시 카드 무효화와 진행 타이머 보존, 이전 대화 본문/화자 보존.
- 보관 off 메모리 화자 정보와 미저장, 선택 저장 실패 시 이전 선택/카드 유지.
- 성공 답변 저장 실패 시 계획·처리 정보·성공 대화 롤백과 동일 카드 재시도.
- 스키마 5 backup API 백업 후 6 이전, 기존 본문·경로를 그대로 유지하고 moru/프로필 1 부여.
- 실제 채팅 목록 선택·화자 표시·클릭 말풍선·기술 오류·720×560 입력 위치와 전환 시 기존 말풍선 숨김.

0.5.0의 실제 commit 실패·런타임/구간 ID·중첩 트랜잭션·장문 50개씩 조회·대화 삭제와 계획 분리·키 형태 canary 거부 검사도 유지했습니다. 키 형태 탐지가 모든 비밀 문자열을 찾는 보장은 아닙니다.

## 중단 후 재검토와 수정

기존 작업의 245개 검사는 정상 완료했습니다. 재개 후 추가 재현 검사에서 응답 화자 오류 두 건을 확인해 수정했습니다.

1. 대화 보관 설정 전환 응답이 선택 캐릭터 대신 기본 moru ID를 갖던 문제.
2. 명령 커밋 직후 설정 신호로 캐릭터가 바뀌면 이미 작성한 답변과 메모리 화자 정보가 새 캐릭터로 덮어써지던 문제.

추가로 일부 입력 오류의 반말 안내, 앱 종료 후 지연 초기 인사 차단을 보완했습니다. GUI 검사마다 남은 테스트 창을 정리해 이후 검사에서 전역 테마가 이전 창에 누적 적용되는 상황도 제거했습니다. 이 테스트 정리는 실제 앱의 장시간 메모리 성능 검증을 대신하지 않습니다. 생활/타이머 상태 응답은 한국어 상태 이름을 사용합니다.

## Windows Qt 자체 실행

`tools/native_smoke.py`를 `QT_QPA_PLATFORM=windows`로 실행했습니다. 전용 `.qa/native-smoke-voices/<UUID>` DB와 `.qa/native-smoke-voices.json`을 사용했습니다.

- 기존 펫/트레이/관리창·계획·캘린더·집중/통계·브리핑·숨김/크기 복원 확인.
- 채팅 미리보기 전 비저장, 확인 저장, 타이머 시작·일시정지·재개 확인.
- 실제 목록에서 3종 말투 선택·응원 응답, 우사기 괄호 형식과 클릭 말풍선 확인.
- 진행 중 전체 종료 뒤 paused 체크포인트, 캐릭터 선택/설정 보존, 잠금 해제, 서비스 타이머 정지 확인.

Qt API로 앱을 조작한 검사이며 실제 OS 마우스/키보드·트레이·알림 클릭을 대신하지 않습니다.

## 화면과 빌드

`tools/render_preview.py`는 전용 `.qa/preview-data-voices/<UUID>` DB에서 앱 위젯만 렌더링합니다. 기존 페이지와 3종 채팅·어두운 화면·720×560 확인/입력 화면을 확인했습니다. 사용자 데이터나 다른 앱을 캡처하지 않았습니다.

PyInstaller **0.5.1 one-folder 빌드**와 포함 파일을 확인했습니다. 모루 64 PNG·아이콘·Qt Windows 플러그인·tzdata Asia/Seoul과 대화 모듈을 포함합니다. 사용자 원본 사진·DB·로그·QA·키 파일은 제외했습니다.

EXE 자체 실행은 미검증입니다. 이전 Windows 앱 제어 정책 거부를 우회하지 않았습니다. 확인된 실행 경로는 `run_windows.bat`의 Python/PySide6 소스 실행입니다.
