# 오프라인 채팅 사용법 — 0.5.1 / PHASE 5A 확장

`run_windows.bat` 실행 → 캐릭터 더블클릭 → 왼쪽 **채팅**을 엽니다. 인터넷·API 키·로그인 없이 동작합니다. 기본 모드는 지원 명령을 처리하며 자유로운 AI 대화는 후속 단계입니다.

## 지원 예시

| 입력 | 동작 |
|---|---|
| 도움말 / 안녕 | 실제 지원 예시 표시 |
| 오늘 할 일 보여줘 | 오늘 서울 날짜의 할 일과 완료 상태 |
| 내일 일정 보여줘 / 2026-11-10 일정 보여줘 | 해당 날짜와 겹치는 일정 조회 |
| 오늘 얼마나 공부했어? | 최근 체크포인트까지 실제 집중 시간 |
| 이번 주 공부 시간 / 이번 달 공부 시간 / 전체 공부 시간 | 설정의 주 시작 요일을 따르는 주간·월간·전체 합계 |
| 25분 집중 시작 / 1시간 30분 집중 시작 | 1~1,440분 검증 후 시작 |
| 5분 짧은 휴식 시작 / 15분 긴 휴식 시작 | 휴식 타이머 시작. 공부 시간에 포함하지 않음 |
| 타이머 일시정지 / 타이머 재개 | 현재 상태가 맞을 때 즉시 처리 |
| 타이머 중지 / 타이머 초기화 | 내용을 확인한 뒤 적용. 과거 공부 기록 보존 |
| 할 일 추가: 자료구조 복습 | 오늘 시간 없는 할 일의 미리보기 |
| 내일 할 일 추가: 자료구조 복습 | 내일 시간 없는 할 일의 미리보기 |
| 내일 오후 3시에 알고리즘 공부 추가해줘 | 할 일/일정 선택 후 절대 날짜·시간 확인 |
| 내일 15:00~16:30 회의 일정 추가해줘 | 시간 범위가 지정된 일정 미리보기 |
| 내일 15:00 회의 일정 추가해줘 | 종료를 시작 1시간 후로 미리보기에서 안내 |
| 내일 종일 휴가 일정 추가해줘 | 하루 종일 일정. 끝은 다음 날 00:00 |
| 오늘 자료구조 복습 완료해줘 | 정확한 제목의 할 일을 확인한 뒤 완료 |
| 오늘 자료구조 복습 완료 취소해줘 | 해당 발생 날짜의 완료 취소 |
| 오늘 자료구조 복습 내일로 옮겨줘 | 예정 날짜 이동. 명시적인 기존 마감 시각은 유지 |
| 오늘 자료구조 복습 삭제해줘 | 대상을 확인한 뒤 삭제 |
| 캘린더 열어줘 / 설정 열어줘 | 기존 관리창의 해당 페이지로 이동 |
| 내 상태 알려줘 | 실제 타이머 상태와 생활 상태 설명 |

날짜는 오늘/내일/모레/`YYYY-MM-DD`, 시각은 `15:00` 또는 `오후 3시` 형식입니다. 제목 변경·메모·분류·알림·새 반복 규칙은 기존 계획/캘린더 편집 화면을 사용합니다. 한 번에 여러 명령, 요일만 지정, 대명사 '이 할 일', 오전/오후 없는 '5시', '정지'처럼 의미가 모호한 명령은 실행하지 않습니다. 날짜를 생략한 완료/삭제/이동의 조회 대상은 오늘이며 다른 날짜를 임의로 뒤지지 않습니다.

## 변경 확인

1. **예시 넣기**는 입력만 채웁니다. **보내기** 또는 Enter로 명령을 처리합니다.
2. 같은 제목이 여러 개면 날짜·시각·종류·분류·번호로 대상을 고릅니다.
3. 반복 이동/삭제는 이번만·이번부터 이후·전체를 고릅니다. 완료/취소는 해당 발생 날짜만 바꿉니다.
4. 대화 아래의 변경 전/후·날짜·반복 범위를 읽고 **확인하고 적용**을 누릅니다. **취소**는 변경하지 않습니다.
5. 카드는 5분 후 만료합니다. 새 명령·새 대화·대화 선택·보관 변경·재시작으로 이전 카드가 무효화됩니다. 다른 화면에서 대상이나 타이머 상태가 달라지면 명령을 다시 입력합니다.

확인 버튼을 반복해서 눌러도 같은 실행 식별 정보로 한 번만 처리합니다. 진행 중 타이머를 새 시작 명령이 덮어쓰지 않습니다. 저장 실패 시 성공으로 표시하지 않으며, 확인 카드 저장 실패는 같은 카드로 다시 시도할 수 있습니다. 일반 입력 오류·실패에는 입력을 유지합니다. 키로 보이는 입력은 저장 전 거부하고 입력란을 비웁니다. 탐지 규칙이 모든 비밀 값을 완벽히 찾는다는 뜻은 아닙니다.

## 대화 보관과 삭제

- **대화 보관** 기본 켜짐: `%LOCALAPPDATA%/DesktopBuddy/buddy.db`에 로컬로 저장합니다.
- 끄면 이후 메시지는 메모리 최대 200개에만 남고 종료 시 사라집니다. 기존 대화는 보존합니다.
- 다시 켜면 새 대화에 지금부터 저장합니다. 메모리 대화를 소급 저장하지 않습니다.
- 대화 선택은 최근 생성한 50개 세션, 메시지는 최근 50개부터 시작합니다. **이전 50개**로 더 읽습니다.
- **대화 삭제**에서 이 대화/모든 대화를 고르고 확인합니다. 일정·할 일·공부 기록은 유지합니다.
- 중복 실행 방지용 UUID·명령 종류·처리 시각은 대화 삭제·보관 끄기와 별도로 보존합니다. 이 정보에는 명령 본문·항목 제목을 넣지 않습니다.
- 대화는 일반 텍스트입니다. HTML·스크립트·임의 파일/셸/프로그램 명령을 실행하지 않습니다.

## 검증과 남은 작업

자동 테스트와 Windows Qt API를 통한 자체 조작, 밝은/어두운 화면과 최소 창 크기를 확인했습니다. 실제 한글 IME·키보드/마우스·DPI·스크린리더·EXE 실행은 [수동 검사](MANUAL_TESTS.md)에 남아 있습니다. 실제 캐릭터 3종 이미지 선택과 AI 연결은 아직 구현하지 않았습니다. 사진 준비 방법은 [캐릭터 안내](../assets/characters/README.md)를 따릅니다.

## 대화 캐릭터 선택

채팅 오른쪽 위 목록에서 모루·치이카와·하치와레·우사기를 선택합니다. 이는 현재 말투 선택이며 화면 캐릭터 이미지는 모루입니다. 말투는 재실행해도 유지되고 이전 메시지에는 당시의 캐릭터 이름을 표시합니다. 캐릭터를 바꾸면 대기 확인 카드는 취소하지만 진행 타이머와 계획은 유지합니다.

`안녕!`, `오늘 공부하기 싫어.`, `나 오늘 시험 잘 봤어!`, `오늘 계획 다 못 지켰어.`, `나 좀 응원해 줘.`, `고마워!`를 사용할 수 있습니다. 치이카와는 짧고 조심스럽게, 하치와레는 밝고 다정하게, 우사기는 감탄사 + (실제 내용)으로 답합니다. 자세한 규칙은 [캐릭터 대화 안내](CHARACTER_DIALOGUE.md)에 있습니다. 코드 분석 등 임의의 질문을 이해하는 AI 대화는 6단계 후속 기능입니다.
