# 개발자 제공 캐릭터 자료

이 폴더는 개발자가 앱에 포함할 캐릭터 자료를 준비하는 위치입니다. 사용자는 앱이 제공하는 목록에서 선택하며, 새 캐릭터는 앱 업데이트로 추가합니다. 개인 이미지 가져오기를 기본 제공하는 방식으로 만들지 않습니다.

현재 앱에는 모루만 연결되어 있고 캐릭터 선택 화면은 아직 구현하지 않았습니다. 여기에 파일을 넣는 것만으로 실행 중인 캐릭터가 바뀌지는 않습니다.

## 먼저 준비할 파일

| 캐릭터 | 기본 이미지 위치 |
|---|---|
| 치이카와 | `chiikawa/idle/frame_001.png` |
| 하치와레 | `hachiware/idle/frame_001.png` |
| 우사기 | `usagi/idle/frame_001.png` |

- 투명 배경 PNG 한 장씩부터 시작할 수 있습니다. 캔버스는 512×512 권장입니다.
- 여러 프레임은 `frame_001.png`, `frame_002.png` 순서로 넣습니다. 같은 캐릭터의 모든 프레임은 같은 캔버스 크기와 중심 위치를 권장합니다.
- 기쁜 표정 자료가 있으면 각 캐릭터의 `happy/`에 같은 이름 규칙으로 넣습니다. 당장은 비워 두어도 됩니다.
- `.gitkeep`은 빈 폴더를 Git에 남기는 파일입니다. 그대로 두면 됩니다.

캐릭터 자료가 준비되면 목록/미리보기/애니메이션 manifest와 첫 선택·설정 변경 기능을 연결합니다. 기존 일정 데이터와 캐릭터 선택은 업데이트 시 유지하는 방향입니다. 자료를 넣기 전에 manifest나 Python 코드를 수정할 필요는 없습니다.

공개 저장소와 배포본에는 사용 허락이 확인된 자료만 포함합니다. 현재 생성한 폴더에는 캐릭터 이미지가 없습니다.
