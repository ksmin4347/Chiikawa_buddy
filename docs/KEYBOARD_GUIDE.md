# 키보드·접근성 사용법 — 0.5.9

관리창 안에서 사용할 수 있는 단축키입니다. 다른 앱을 조작하는 전역 단축키로 등록하지 않습니다. 왼쪽 **키보드 안내 · F1** 버튼에서도 같은 내용을 볼 수 있습니다. 너비 800 논리 픽셀 미만에서는 상단 **화면 선택 메뉴**와 **안내 · F1** 버튼이 나타납니다. 메뉴는 방향키로 고르고 기존 Ctrl+1~9도 사용할 수 있습니다. 창 크기 변경으로 현재 메뉴가 숨겨지면 표시되는 메뉴로 초점을 옮깁니다.

| 키 | 동작 |
|---|---|
| Ctrl+1 | 홈 |
| Ctrl+2 | 오늘의 계획 · 빠른 제목 입력으로 이동 |
| Ctrl+3 | 캘린더 · 날짜 입력으로 이동 |
| Ctrl+4 | 집중 타이머 · 시작/일시정지/재개 버튼으로 이동 |
| Ctrl+5 | 공부 통계 · 기간 선택으로 이동 |
| Ctrl+6 | 생활·브리핑 |
| Ctrl+7 또는 Ctrl+L | 채팅 · 명령 입력으로 이동 |
| Ctrl+8 | 캐릭터 · 상태 미리보기 선택으로 이동 |
| Ctrl+9 | 설정 · 부르는 이름으로 이동 |
| Ctrl+Enter | 채팅의 현재 확인 카드 적용 |
| Escape | 채팅 확인 카드 취소 또는 열린 대화상자 닫기 |
| Tab / Shift+Tab | 다음 / 이전 항목으로 이동 |
| Space | 초점이 있는 버튼 누르기 |
| Enter | 채팅 보내기, 빠른 할 일 추가, 편집창 저장 |
| F1 | 키보드 안내 열기 |

메뉴를 이동해도 아직 보내지 않은 채팅 초안은 유지됩니다. 타이머 화면으로 이동하는 단축키 자체는 타이머를 시작하거나 멈추지 않습니다. 진행 중에는 일시정지, 멈춘 상태에서는 재개 버튼으로 초점이 이동합니다.

## 채팅을 키보드로 사용하기

1. `Ctrl+L`로 입력칸에 이동합니다.
2. `할 일 추가: 자료구조 복습`을 입력하고 `Enter`를 누릅니다.
3. 표시된 제목·날짜·분류를 확인한 뒤 `Ctrl+Enter`로 적용하거나 `Escape`로 취소합니다.

대상/범위를 고르는 카드라면 방향키로 선택하고 `Ctrl+Enter`를 누릅니다. 선택을 마친 뒤 표시되는 최종 확인 카드는 다시 확인해야 저장합니다. 5분 지난 카드, 변경된 대상, 같은 요청의 중복 적용은 기존 검증을 거치며 단축키가 이를 건너뛰지 않습니다.

단축키의 자동 반복을 꺼 두었습니다. 키를 길게 누르는 대신 손을 뗀 뒤 다음 확인 내용을 읽고 다시 누릅니다.

`Escape`로 확인 카드를 취소해도 입력칸의 다음 명령 초안은 지우지 않습니다. 한글 조합 이벤트가 진행되는 동안에는 보내기·키보드 적용·취소를 실행하지 않습니다. 입력칸에서 나가면 조합 보호 상태를 해제합니다. 실제 Windows IME별 조합·한/영 전환은 별도 실사용 확인 대상입니다.

편집 대화상자가 열려 있는 동안 관리창 뒤의 메뉴 이동·채팅 확인 단축키는 작동하지 않습니다. `F1` 안내를 닫으면 이전 입력 초점으로 돌아옵니다.

## 화면 읽기 지원

타이머 종류·시간·연결할 할 일·분류, 생활 설정, 반복 종료 조건, 통계 목록과 편집 입력에 구분되는 접근성 이름을 제공합니다. 타이머 남은 시간과 그래프의 날짜별 시간은 접근성 설명에도 담습니다.

접근성 기능이 활성화된 상태에서 현재 화면의 확인 카드·오류·타이머 상태 변경을 Qt 접근성 안내 이벤트로 알립니다. 타이머 매 틱마다 안내하지 않으며 보이지 않는 화면에서도 안내하지 않습니다. 화면 읽기 프로그램의 실제 음성 전달과 키 배치는 이번에 실사용 인수하지 않았습니다.

검증은 [0.5.7 검사 기록](PHASE_5C_REPORT.md), 실제 입력 확인은 [수동 목록](MANUAL_TESTS.md)을 참고하세요.

0.5.8의 작은 창·초점 이동 회귀는 [검토 기록](AUDIT_REPORT_0.5.8.md)을 따릅니다. 실제 Windows 키보드·스크린리더 인수는 계속 남아 있습니다.

설정 아래의 **데이터 저장 폴더**는 읽기 전용입니다. 입력칸에 초점을 두고 Ctrl+A로 전체 경로를 선택한 뒤 Ctrl+C로 복사할 수 있습니다. 긴 경로도 입력칸 안에서 확인하며 폴더 위치를 변경하지 않습니다. [0.5.9 Windows Qt 검사](AUDIT_REPORT_0.5.9.md)를 참고하세요.
