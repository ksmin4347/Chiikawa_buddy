# Windows에서 사용하기 — 0.6.1

## 시작

이 PC의 바탕화면에서 **먼작귀** 우사기 아이콘을 더블클릭하면 콘솔 창 없이 실행합니다. 프로젝트의 `desktop_buddy_entry.py`를 `.venv\Scripts\pythonw.exe`로 실행하는 바로가기입니다. 앱 표시 이름과 아이콘을 바꿔도 기존 `%LOCALAPPDATA%\DesktopBuddy` 데이터는 유지합니다.

이 PC에서는 `run_windows.bat`을 더블클릭합니다. 첫 선택 화면에서 캐릭터를 고르고, 화면 오른쪽 아래의 캐릭터를 더블클릭하면 관리창이 열립니다. 홈·오늘의 계획·캘린더·집중 타이머·공부 통계·생활·브리핑·채팅·캐릭터·설정을 사용할 수 있습니다.

다른 PC에서 소스를 준비하거나 0.1.0 환경을 업데이트할 때에는 Python 3.12 이상 설치 후 `setup_windows.bat`을 한 번 실행합니다. 준비 과정만 인터넷이 필요합니다. 오류가 나면 실행 창이 유지됩니다.

관리창이 좁아지면 왼쪽 메뉴 대신 위쪽의 **화면 선택 메뉴**를 사용합니다. 너비 800 논리 픽셀 미만에서 전환하며 최소 크기는 560×360입니다. 아래 내용은 세로 스크롤로 확인합니다. 창을 늘리거나 줄여도 채팅 입력·확인 대기 내용·집중 시간은 유지됩니다.

## 오늘의 계획

1. '오늘의 계획'에서 제목을 적고 Enter 또는 '추가'를 누릅니다.
2. 왼쪽 체크박스로 완료·완료 취소를 합니다. 완료한 항목은 캐릭터가 짧게 응원합니다.
3. 항목을 더블클릭하거나 선택 후 '수정'을 누르면 메모·예정 날짜·선택 시작 시간·마감·우선순위·카테고리·반복·알림을 바꿉니다.
4. '날짜 바꾸기'는 같은 편집창의 날짜 항목으로 이동합니다.
5. '이전 미완료'는 선택 날짜보다 앞에 남아 있는 항목을 보여줍니다. 앱이 자동으로 완료하거나 없애지 않습니다.
6. '삭제'는 확인 후 실행합니다. 반복 항목은 이번만/이후/전체를 선택합니다.

## 캘린더

- 월간은 날짜별 첫 항목과 추가 개수를 표시합니다. 날짜를 고르면 아래에 모든 항목이 보입니다.
- 날짜 빈 영역을 더블클릭하거나 '일정 추가'를 누릅니다.
- '주간'과 '일간'은 시간표입니다. 위쪽은 종일 영역이고 아래쪽은 스크롤하는 시간대입니다.
- 시간표 블록을 클릭하거나 아래 목록을 더블클릭하면 수정합니다. 짧아 글씨가 다 보이지 않으면 마우스를 올리거나 아래 목록에서 확인합니다.
- 여러 일정이 겹치면 열을 나눕니다. 자정을 넘기는 일정도 해당 날짜들에 보입니다.
- 종일 일정의 화면상 종료 날짜는 포함합니다. 예를 들어 28~29일을 선택하면 두 날짜에 표시됩니다.
- 위쪽 화살표, 오늘 버튼, 날짜 입력으로 이동합니다. 주 시작은 설정에서 일/월요일로 선택합니다.

## 반복과 분류

매주 특정 요일, 평일만 선택, 2주 간격, 매월 같은 날짜, 매년 같은 날짜를 설정할 수 있습니다. 종료 날짜와 종료 횟수 중 하나를 선택합니다. 31일이 없는 달, 윤년이 아닌 2월 29일은 건너뜁니다.

수정·삭제 범위는 원래 반복 날짜를 기준으로 합니다. 이번만 시간을 옮겨도 다른 날짜는 유지됩니다. 이후 수정은 과거 반복을 남기고 이후 구간을 분리합니다. 반복을 끄면 개별 수정과 완료 이력은 일회성 항목으로 보존합니다.

카테고리 관리에서 분류 이름과 색을 바꿉니다. 분류를 지워도 등록한 항목은 '분류 없음'으로 남습니다.

## 알림

일정은 시작 시각, 할 일은 입력한 마감 시각을 기준으로 알림을 설정합니다. 현재 화면은 한국(서울) 시간입니다. 앱이 완전히 종료되면 알림을 보내지 못합니다.

설정에서 알림 전체 끄기, 잠시 쉬기, 방해 금지 시간을 선택합니다. 이 앱의 알림만 제한합니다. 방해 금지 중 알림을 나중에 몰아 띄우지 않습니다. 시작·복귀 시 최근 5분 이내 항목만 확인하고, 같은 알림은 재실행 후에도 반복하지 않습니다. 실제 Windows 토스트 표시는 OS 설정에 영향을 받으며 수동 확인이 필요합니다.

## 집중 타이머와 통계

1. '집중 타이머'에서 집중/짧은 휴식/긴 휴식과 이번 시간을 선택합니다.
2. 필요하면 할 일 날짜·항목·분류를 선택하고 시작합니다. 할 일을 자동 완료하지 않습니다.
3. 일시정지·재개·중지를 사용할 수 있습니다. 초기화는 진행 중일 때 확인을 거치며 지난 기록은 남습니다.
4. 기본 25/5/15분과 4회 간격을 바꾸고 자동 다음 단계를 선택할 수 있습니다. 휴식은 건너뛸 수 있습니다.
5. 작은 타이머는 항상/집중 중/마우스 올림/숨김 중 선택합니다. 캐릭터를 숨기면 함께 숨고 기록은 계속됩니다.
6. 절전·긴 응답 지연·시계 변경·앱 재실행 후에는 일시정지로 복구합니다. 내용을 확인하고 직접 재개합니다. 꺼져 있던 시간은 적립하지 않습니다.
7. '공부 통계'에서 실제 집중·완료 수·평균·최근 날짜, 7/30일·주별/월별 그래프와 공부 달력을 봅니다. 주 시작은 캘린더 설정과 같습니다.
8. 종료한 기록을 고른 뒤 분류를 바꾸거나 확인 후 삭제하면 집계도 갱신됩니다. 시간은 직접 덮어쓰지 않습니다.

정상 종료는 마지막 진행을 저장합니다. 강제 종료 시 마지막 체크포인트 뒤 약 5초가 사라질 수 있습니다. 휴식과 일시정지는 집중에 포함하지 않으며, 중지한 집중은 누적에 포함합니다. 완료 수·평균은 끝까지 마친 집중 기준입니다. OS의 실제 절전/토스트 확인은 수동 검증이 남았습니다.

## 생활·브리핑

1. 메뉴에서 감정 기능·최소 집중 시간·공백 기준·안부 간격을 정합니다. 기본 주말은 쉬는 날입니다.
2. 휴가/휴식 기간의 시작~종료 날짜를 추가합니다. 해당 기간은 자동 적용됩니다. 지난 휴식도 남겨 두면 공백에서 빠집니다.
3. 수면을 켜고 시간대를 정합니다. 집중이 진행 중이면 공부 모습이 우선합니다.
4. 집중 중 천천히/작게/타이머만/모두 숨김을 고를 수 있습니다. 끝나면 저장된 선호 설정으로 돌아가고 직접 숨긴 상태는 유지합니다.
5. Windows 전체 화면 감지는 선택 사항이며 일부 앱은 놓칠 수 있습니다. 트레이·우클릭의 직접 숨김/캐릭터 찾기를 함께 사용합니다. 찾기는 현재 자동 숨김 구간에서도 직접 표시를 허용합니다.
6. 자동 브리핑을 켜고 앱 시작 시/시각/상세 여부를 정합니다. 자동 안내는 날짜당 한 번, 직접 보기는 언제든 가능합니다. 카드에서 오늘의 계획으로 이동하거나 닫습니다.
7. 큰 시계 변경/역행 안내가 나오면 OS 날짜를 먼저 확인한 뒤 '현재 날짜로 계속'을 누릅니다.
8. 공부 기록을 끄면 새 집중만 통계에서 제외합니다. 기존 기록·현재 진행 중인 세션의 설정은 유지합니다. 임시 상태는 복구에 사용하고 끝난 미기록 세션은 정리합니다.

자동 수면·브리핑·전체 화면 숨김은 기본 off입니다. 첫 유효 집중을 완료하기 전에는 공백 감정이 생기지 않습니다. 타이머 완료만 방해 금지/수면 중 허용하는 선택지도 있습니다. 실제 Windows 절전·전체 화면 앱·토스트·여러 배율은 수동 확인이 남습니다.

## 숨김과 종료

관리창 닫기는 창만 숨깁니다. 캐릭터 숨김은 펫·말풍선·작은 타이머를 감춥니다. 집중 기록은 계속됩니다. 전체 종료는 관리창·우클릭·트레이의 '프로그램 종료'를 사용합니다.

안 보이면 트레이에서 복원하거나 앱을 다시 실행하세요. 기존 앱을 불러오고 관리창을 엽니다. 오른쪽 아래로 위치 복구도 가능합니다.

## 저장과 업데이트

`%LOCALAPPDATA%\DesktopBuddy\buddy.db`에 저장합니다. 0.1.0~0.3.0 DB는 자동 백업 후 새 스키마로 이전하며 설정과 위치를 유지합니다. 이전 중 오류가 있어도 DB를 초기화하지 않습니다. 원본과 `buddy.<시각>.backup.db`를 보관하세요. 수동 백업·복원 버튼은 아직 없습니다.

`dist\releases\Meonjakgwi-0.6.1-windows-x64.zip`은 로컬 배포 후보입니다. ZIP 전체를 새 폴더에 압축 해제하고 `DesktopBuddy.exe`와 `_internal`을 함께 둡니다. 업데이트 전 트레이에서 종료하고 새 폴더를 사용하면 기존 `%LOCALAPPDATA%\DesktopBuddy` 데이터는 유지됩니다. Python 없는 PC의 실행은 아직 검증하지 않았습니다.

이 PC에서 이전 0.5.8 EXE 실행은 **Windows 앱 제어 정책으로 차단**되었습니다. 0.5.9의 Windows Qt 소스 검사는 EXE 실제 실행 검증을 대신하지 않습니다. 보안 설정을 바꾸지 않았으며 현재는 바탕화면 먼작귀 또는 `run_windows.bat` 소스 실행을 사용합니다. [ZIP·SHA-256 검증과 빌드 방법](RELEASE_GUIDE.md)을 참고하세요.

0.6.1은 **설정 → API 키·연결 관리**에서 마스킹 입력·Windows 보관·교체·삭제와 명시적인 연결 테스트를 제공합니다. 키 저장/상태 조회는 로컬 처리입니다. 테스트 성공 후 **채팅 → 온라인 AI 대화**를 직접 켭니다. 테스트/전송에는 API 비용이 생길 수 있으며 앱 재실행은 오프라인입니다. 키가 없어도 기존 기능을 사용할 수 있습니다. [온라인 사용법](ONLINE_GUIDE.md)·[키 관리](API_KEY_GUIDE.md)를 따릅니다.

0.5.9에서는 설정의 **데이터 저장 폴더**를 읽기 전용 입력칸으로 표시합니다. 경로가 길어도 설정 화면을 넓히지 않으며 Ctrl+A로 전체를 선택하고 Ctrl+C로 복사할 수 있습니다. 이 칸에서 실제 저장 폴더를 바꾸지는 않습니다.

0.5.7은 관리창에서 **Ctrl+1~9**, 채팅 **Ctrl+L / Ctrl+Enter / Escape**, **F1** 키보드 안내를 지원합니다. 업데이트 후 재실행하면 사용할 수 있습니다. [키보드·접근성 사용법](KEYBOARD_GUIDE.md)을 참고하세요.

0.5.6은 작은 관리창·긴 제목과 분류·캘린더·목록 갱신을 보완했습니다. 창이 작으면 세로 스크롤로 아래 버튼을 사용할 수 있습니다. 업데이트 후에는 트레이의 **프로그램 종료**를 누르고 바탕화면 **먼작귀**를 다시 실행하세요. 설정·계획·공부 데이터는 기존 폴더를 사용합니다. [재점검 결과](AUDIT_REPORT_0.5.6.md)를 확인할 수 있습니다.

수동 확인 목록: [MANUAL_TESTS.md](MANUAL_TESTS.md). 다음은 실제 API/입력/접근성 인수와 요청에 따른 6C AI 작업 제안입니다.

## 오프라인 채팅 — PHASE 5A

관리창의 채팅에서 `오늘 할 일 보여줘`, `25분 집중 시작`, `할 일 추가: 자료구조 복습`을 입력합니다. 추가/수정/완료/삭제와 타이머 중지/초기화는 확인 후 적용합니다. 같은 제목과 반복 범위는 먼저 선택합니다. 5분 지난 카드나 다른 화면에서 바뀐 대상은 다시 입력합니다.

대화 보관은 기본 켜짐이며 끄면 이후 메시지는 실행 중에만 유지합니다. 대화 삭제는 계획과 공부 기록을 삭제하지 않습니다. 캐릭터 3종을 선택할 수 있으며 AI 대화는 위 연결 절차를 직접 마친 뒤 사용합니다. AI 모드에서는 앱 명령을 실행하지 않습니다. 전체 예시는 [채팅 안내](CHAT_GUIDE.md)를 참고하세요. 0.5.0 이하 DB는 backup API로 백업한 뒤 스키마 6으로 이전합니다.

## 캐릭터별 말투 — 0.5.2

채팅 오른쪽 위에서 치이카와·하치와레·우사기를 고르면 새 답변과 클릭/완료/공백 말풍선에 적용됩니다. `나 좀 응원해 줘.`나 `오늘 공부하기 싫어.`로 확인할 수 있습니다. 우사기는 감탄사 뒤 괄호 안에 실제 내용을 표시합니다. 선택은 저장하며 기존 대화는 당시 캐릭터 이름과 내용을 유지합니다. 같은 캐릭터의 실제 그림도 함께 바뀝니다.


## 캐릭터 선택과 빠른 집중 — 0.5.2

새로 설치하면 3종 선택 화면이 열립니다. 나중에 선택해도 앱을 사용할 수 있습니다. 관리창 **캐릭터**에서 언제든 바꾸고 상태별 모습을 미리 볼 수 있습니다. 그림·말투는 함께 바뀌며 계획·공부·위치는 유지합니다. 기본 이름은 선택한 캐릭터를 따르고 직접 정한 별명은 그대로입니다. 걱정/수면 그림이 없는 팩은 평소 모습으로 표시하지만 생활/타이머 규칙은 계속 적용합니다.

집중 화면의 15/25/30/60분 버튼은 시간을 채웁니다. 펫 우클릭 **집중 바로 시작**은 해당 시간으로 즉시 시작하며 진행 중에는 비활성화합니다. 같은 메뉴에서 일시정지/재개/중지를 사용할 수 있습니다. 집중 화면의 **작은 타이머 모양**에서 원형 진행을 고를 수 있습니다.


## 바라보기·돌아다니기 — 0.5.5

앱을 실행 중이었다면 트레이에서 프로그램 종료 후 바탕화면 먼작귀를 다시 실행합니다. 관리창 **캐릭터**에서 치이카와·하치와레·우사기 중 선택하고 아래 움직임 옵션을 정합니다. 마우스 방향 바라보기는 기본 켜져 있습니다. 돌아다니기는 직접 켜며 18~35초의 평소 대기 후 현재 모니터 안에서 좌우로 짧게 움직입니다.

집중·수면·방해 금지·숨김·움직임 줄이기 중에는 두 기능을 멈춥니다. 포인터가 가까워지거나 드래그/우클릭 메뉴를 쓰면 이동을 중단합니다. 관리창·첫 선택·말풍선을 보는 동안도 이동을 미룹니다. 긴 응답 공백 뒤에는 이전 경로로 뛰어가지 않습니다. 위치와 설정은 저장되며 모루에는 해당 프레임이 없어 옵션 안내를 표시합니다.


## 완료 공연·음악 — 0.5.5

실행 중이면 트레이에서 프로그램 종료 후 바탕화면 먼작귀를 다시 실행합니다. 관리창 **집중 타이머** 아래 **집중 완료 축하**에서 공연과 음악을 고릅니다. 기본은 짧은 무음 축하입니다. 음악을 켜면 선택한 캐릭터의 곡을 재생하며 기본 모루에는 음악이 없습니다.

축하 미리보기는 공부 기록을 만들지 않습니다. 축하·음악 멈추기 또는 캐릭터 클릭/우클릭으로 멈춥니다. 타이머 진행/일시정지 중에는 미리보기가 비활성화됩니다. 자동 다음 단계는 지연 없이 시작하며 짧게만 축하합니다. 숨김·수면·방해 금지·완료 알림 off에서는 자동 축하를 쉬고, 움직임 줄이기는 동작만 줄입니다. 오류는 같은 카드에 표시하며 공부 기록은 유지합니다.
