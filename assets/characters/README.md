# 캐릭터 사진 넣는 방법

현재 **치이카와·하치와레·우사기 3종을 바로 선택**할 수 있습니다. 실행용 자료는 `assets/character_packs/<id>/`에 연결했습니다. 이 `assets/characters` 폴더는 이후 사진 교체·추가를 위한 **작업 원본 보관소**입니다. 여기에 사진을 넣으면 검토·팩 갱신 후 앱 업데이트에 반영합니다. 원본을 자동으로 불러오거나 공개하지 않습니다. [선택·팩 안내](../../docs/CHARACTER_GUIDE.md)를 확인하세요.

사용자는 배포된 앱에서 개발자가 제공한 캐릭터 중 선택합니다. 개인 이미지 가져오기 메뉴는 만들지 않고, 새 종류는 개발자가 앱 업데이트로 추가합니다.

## 1. 내가 넣을 위치

이 PC의 프로젝트에서 아래 폴더를 사용합니다.

```text
C:\Users\user\Documents\ChatGPT\먼작귀 ai 에이전트 만들기\assets\characters\
```

| 캐릭터 | 폴더 이름 | 첫 기본 사진의 권장 위치 |
|---|---|---|
| 치이카와 | chiikawa | chiikawa/idle/frame_001.png |
| 하치와레 | hachiware | hachiware/idle/frame_001.png |
| 우사기 | usagi | usagi/idle/frame_001.png |

예를 들어 치이카와의 집중 사진은 `chiikawa/focus/frame_001.png`, 쉬는 사진은 `chiikawa/break/frame_001.png`에 둡니다. 각 상태에서 파일 번호는 001부터 다시 시작합니다. `.gitkeep`은 빈 폴더 보관용이므로 그대로 둬도 됩니다.

**기존 원본은 지우거나 덮어쓰지 마세요.** 2026-11-03 확인 기준 치이카와 폴더에 PNG 4개·GIF 23개가 있습니다. 이 원본의 이름을 지금 억지로 바꾸지 않아도 됩니다. 적용 작업에서 대표 그림을 골라 작업용 PNG를 따로 만들고 순서를 정합니다. 하치와레·우사기도 같은 방식으로 준비합니다.

## 2. 어떤 사진이면 되는지

- 권장: **투명 배경 PNG(RGBA), 512×512px**, 한 파일에 한 캐릭터의 한 자세.
- 1,024×1,024px도 원본으로 받을 수 있습니다. 배포용 크기는 정리할 때 통일합니다.
- 캐릭터별로 캔버스 크기·발바닥 기준 위치·그림 배율을 맞춥니다. 프레임 사이에서 불필요하게 크기/위치가 흔들리지 않게 합니다.
- 귀·손·발·소품이 잘리지 않게 5~10% 정도 여백을 두고 큰 동작도 캔버스 안에 넣습니다.
- 흰색 배경이나 체크무늬가 그림에 들어 있으면 실제 투명이 아닙니다. 투명도는 적용 전에 확인합니다.
- 말풍선 문장·타이머 숫자·앱 버튼은 사진에 넣지 않습니다. 책·연필·컵 같은 동작 소품은 넣어도 됩니다.
- 단순 확대만으로 작은 이미지가 선명해지지는 않습니다. 원본이 크고 선명한 편이 좋습니다.

## 3. 상황별로 어떤 표정이 필요한지

| 폴더 | 준비할 모습 | 현재/예정 사용 상황 | 움직임을 만들 때 권장 장수 |
|---|---|---|---|
| idle | 평소 편하게 서 있기 | 기본 모습·누락 상태의 대체 | 4~8 |
| happy | 웃기·손 흔들기 | 클릭 인사·긍정 반응 | 4~8 |
| focus | 책 읽기·필기·집중 표정 | 집중 타이머 진행 | 2~6 |
| break | 편안히 쉬기·기지개 | 휴식 타이머 진행 | 2~6 |
| complete | 박수·밝게 웃는 짧은 축하 | 집중 완료 | 4~8 |
| sad | 부담스럽지 않은 시무룩한 표정 | 유효 공부 공백 기준 충족 | 2~4 |
| sleep | 눈을 감고 잠들기 | 설정에서 켠 수면 시간 | 2~4 |
| worried | 살짝 걱정하는 표정 | 시무룩해지기 전 단계. 선택 준비 | 2~4 |
| thinking | 고개 갸웃·생각하는 표정 | 5·6단계 채팅 처리 때 연결 예정 | 2~6 |
| talking | 입 모양·작은 손짓 변화 | 5·6단계 답변 표시 때 연결 예정 | 3~6 |
| blink | 눈 뜸→감음→다시 뜸 | idle 안에 넣어도 됨 | 2~3 |
| sleepy | 하품·졸린 표정 | 추가 상태, 별도 발동은 후속 구현 | 2~4 |
| excited | 신나게 팔 들기·작은 점프 | 추가 반응, 발동 조건 후속 구현 | 6~10 |
| surprised | 눈이 커짐·살짝 움찔 | 추가 반응, 알림마다 자동 발동하지 않음 | 2~4 |

원래 준비한 13개 폴더에 worried는 없을 수 있습니다. 필요하면 같은 위치에 새로 만들어도 됩니다. 없는 걱정 표정을 sad로 대체해 일찍 슬퍼지게 하지는 않습니다.

현재 모루의 공백 판단은 기본 15분 이상 실제 집중을 **완료한 기록**부터 적용하고, 첫 사용자·주말·휴식 기간·기록 off 예외를 반영합니다. 앱을 켜지 않았다는 이유만으로 슬퍼지는 구조가 아닙니다.

## 4. 몇 장부터 준비하면 되는지

가장 적게 시작하려면 **캐릭터마다 idle 한 장**, 총 3장이 필요합니다. 이 경우 없는 상태는 같은 캐릭터의 기본 사진으로 보이므로 상황별 표정 변화는 제한됩니다.

원하는 상황별 변화를 보려면 **idle/happy/focus/break/complete/sad/sleep 7가지에 한 장씩**, 세 캐릭터 합계 21개 상태 파일을 권장합니다. worried까지 준비하면 24개 상태 파일입니다. happy와 complete에 같은 그림을 재사용해도 되므로 반드시 전부 다른 그림을 그려야 하는 뜻은 아닙니다.

- 상태마다 1장: 상황이 바뀔 때 표정이 바뀝니다.
- 상태마다 서로 다른 연속 프레임 여러 장: 그 상태 안에서도 움직입니다.
- 같은 그림을 여러 장 복사: 새로운 동작이 만들어지지는 않습니다.

happy 4장은 '미소→손 들기→손 흔들기→원래 자세'처럼 이어지게 준비합니다. 서로 관계없는 포즈나 여러 GIF를 한 상태의 연속 동작처럼 무작정 섞지 않습니다. 재생 속도·반복·반응 뒤 복귀는 개발 쪽에서 설정합니다.

## 5. GIF와 첨부 방법

GIF는 **원본으로 제공해도 됩니다.** 현재 앱에 넣어 움직임을 그대로 자동 적용하는 기능은 없습니다. 적용할 때 누적 프레임·투명도·프레임별 지연을 확인하면서 PNG 연속 프레임으로 정리합니다. APNG는 작업용 PNG로 정리하며, PNG 스프라이트 시트는 셀 크기·행/열을 manifest에 지정해 사용할 수 있습니다. JPG·스크린샷은 배경 정리가 필요할 수 있습니다.

전달 방법은 둘 중 하나입니다.

1. 위 폴더에 넣고 '치이카와 focus는 이 GIF를 써줘'처럼 대표 파일과 상황을 알려주기.
2. 캐릭터/상태 폴더 구조를 유지한 ZIP 또는 PNG를 첨부하고 캐릭터·상황을 함께 적기.

ZIP은 개발 자료 전달용입니다. 배포된 앱 사용자가 ZIP이나 개인 사진을 가져오는 기능을 의미하지 않습니다. 기본 선택 미리보기는 idle의 첫 사진을 사용하므로 별도 썸네일은 당장 없어도 됩니다.

## 6. 이후 사진을 교체할 때 개발 쪽에서 할 작업

원본 확인 → 사용할 그림 선택 → 투명도·크기·정렬·프레임 순서 정리 → 상태별 manifest → 팩 검증 → 3종 목록·첫 선택/설정 변경 연결 → 현재 타이머/감정과 전환 검사 → 허용된 자료만 빌드 포함 순서입니다.

사용자가 Python 코드나 manifest를 직접 만들 필요는 없습니다. 아래는 **단일 PNG 프레임을 사용할 때의 예시**입니다. 현재 번들 팩은 아틀라스와 집중 PNG 3장을 함께 사용합니다.

```json
{
  "id": "chiikawa",
  "name": "치이카와",
  "states": {
    "idle": {
      "fps": 3,
      "loop": true,
      "frames": ["idle/frame_001.png"]
    },
    "complete": {
      "fps": 6,
      "loop": false,
      "frames": ["complete/frame_001.png"]
    }
  }
}
```

원본 자료는 현재처럼 로컬에 보존합니다. 빌드는 기본 모루·아이콘과 고정 3종 팩의 manifest/atlas/focus PNG만 포함하며 이 원본 폴더는 제외합니다.
