# Windows에서 사용하기 — 0.3.0

## 시작

이 PC에서는 `run_windows.bat`을 더블클릭합니다. 화면 오른쪽 아래의 모루를 더블클릭하면 홈·오늘의 계획·캘린더·집중 타이머·공부 통계·설정 관리창이 열립니다.

다른 PC에서 소스를 준비하거나 0.1.0 환경을 업데이트할 때에는 Python 3.12 이상 설치 후 `setup_windows.bat`을 한 번 실행합니다. 준비 과정만 인터넷이 필요합니다. 오류가 나면 실행 창이 유지됩니다.

## 오늘의 계획

1. '오늘의 계획'에서 제목을 적고 Enter 또는 '추가'를 누릅니다.
2. 왼쪽 체크박스로 완료·완료 취소를 합니다. 완료한 항목은 캐릭터가 짧게 응원합니다.
3. 항목을 더블클릭하거나 선택 후 '수정'을 누르면 메모·예정 날짜·선택 시작 시간·마감·우선순위·카테고리·반복·알림을 바꿉니다.
4. '날짜 바꾸기'는 같은 편집창의 날짜 항목으로 이동합니다.
5. '이전 미완료'는 선택 날짜보다 앞에 남아 있는 항목을 보여줍니다. 앱이 자동으로 완료하거나 없애지 않습니다.
6. '삭제'는 확인 후 실행합니다. 반복 항목은 이번만/이후/전체를 선택합니다.

## 캘린더

- 월간은 날짜별 첫 항목과 추가 개수를 표시합니다. 날짜를 고르면 아래에 모든 항목이 보입니다.
- 날짜 빈 영역을 더블클릭하거나 '일정 추가'를 누릅니다.
- '주간'과 '일간'은 시간표입니다. 위쪽은 종일 영역이고 아래쪽은 스크롤하는 시간대입니다.
- 시간표 블록을 클릭하거나 아래 목록을 더블클릭하면 수정합니다. 짧아 글씨가 다 보이지 않으면 마우스를 올리거나 아래 목록에서 확인합니다.
- 여러 일정이 겹치면 열을 나눕니다. 자정을 넘기는 일정도 해당 날짜들에 보입니다.
- 종일 일정의 화면상 종료 날짜는 포함합니다. 예를 들어 28~29일을 선택하면 두 날짜에 표시됩니다.
- 위쪽 화살표, 오늘 버튼, 날짜 입력으로 이동합니다. 주 시작은 설정에서 일/월요일로 선택합니다.

## 반복과 분류

매주 특정 요일, 평일만 선택, 2주 간격, 매월 같은 날짜, 매년 같은 날짜를 설정할 수 있습니다. 종료 날짜와 종료 횟수 중 하나를 선택합니다. 31일이 없는 달, 윤년이 아닌 2월 29일은 건너뜁니다.

수정·삭제 범위는 원래 반복 날짜를 기준으로 합니다. 이번만 시간을 옮겨도 다른 날짜는 유지됩니다. 이후 수정은 과거 반복을 남기고 이후 구간을 분리합니다. 반복을 끄면 개별 수정과 완료 이력은 일회성 항목으로 보존합니다.

카테고리 관리에서 분류 이름과 색을 바꿉니다. 분류를 지워도 등록한 항목은 '분류 없음'으로 남습니다.

## 알림

일정은 시작 시각, 할 일은 입력한 마감 시각을 기준으로 알림을 설정합니다. 현재 화면은 한국(서울) 시간입니다. 앱이 완전히 종료되면 알림을 보내지 못합니다.

설정에서 알림 전체 끄기, 잠시 쉬기, 방해 금지 시간을 선택합니다. 이 앱의 알림만 제한합니다. 방해 금지 중 알림을 나중에 몰아 띄우지 않습니다. 시작·복귀 시 최근 5분 이내 항목만 확인하고, 같은 알림은 재실행 후에도 반복하지 않습니다. 실제 Windows 토스트 표시는 OS 설정에 영향을 받으며 수동 확인이 필요합니다.

## 집중 타이머와 통계

1. '집중 타이머'에서 집중/짧은 휴식/긴 휴식과 이번 시간을 선택합니다.
2. 필요하면 할 일 날짜·항목·분류를 선택하고 시작합니다. 할 일을 자동 완료하지 않습니다.
3. 일시정지·재개·중지를 사용할 수 있습니다. 초기화는 진행 중일 때 확인을 거치며 지난 기록은 남습니다.
4. 기본 25/5/15분과 4회 간격을 바꾸고 자동 다음 단계를 선택할 수 있습니다. 휴식은 건너뛸 수 있습니다.
5. 작은 타이머는 항상/집중 중/마우스 올림/숨김 중 선택합니다. 캐릭터를 숨기면 함께 숨고 기록은 계속됩니다.
6. 절전·긴 응답 지연·시계 변경·앱 재실행 후에는 일시정지로 복구합니다. 내용을 확인하고 직접 재개합니다. 꺼져 있던 시간은 적립하지 않습니다.
7. '공부 통계'에서 실제 집중·완료 수·평균·최근 날짜, 7/30일·주별/월별 그래프와 공부 달력을 봅니다. 주 시작은 캘린더 설정과 같습니다.
8. 종료한 기록을 고른 뒤 분류를 바꾸거나 확인 후 삭제하면 집계도 갱신됩니다. 시간은 직접 덮어쓰지 않습니다.

정상 종료는 마지막 진행을 저장합니다. 강제 종료 시 마지막 체크포인트 뒤 약 5초가 사라질 수 있습니다. 휴식과 일시정지는 집중에 포함하지 않으며, 중지한 집중은 누적에 포함합니다. 완료 수·평균은 끝까지 마친 집중 기준입니다. OS의 실제 절전/토스트 확인은 수동 검증이 남았습니다.

## 숨김과 종료

관리창 닫기는 창만 숨깁니다. 캐릭터 숨김은 펫·말풍선·작은 타이머를 감춥니다. 집중 기록은 계속됩니다. 전체 종료는 관리창·우클릭·트레이의 '프로그램 종료'를 사용합니다.

안 보이면 트레이에서 복원하거나 앱을 다시 실행하세요. 기존 앱을 불러오고 관리창을 엽니다. 오른쪽 아래로 위치 복구도 가능합니다.

## 저장과 업데이트

`%LOCALAPPDATA%\DesktopBuddy\buddy.db`에 저장합니다. 0.1.0/0.2.0 DB는 자동 백업 후 새 스키마로 이전하며 설정과 위치를 유지합니다. 이전 중 오류가 있어도 DB를 초기화하지 않습니다. 원본과 `buddy.<시각>.backup.db`를 보관하세요. 수동 백업·복원 버튼은 아직 없습니다.

`dist\DesktopBuddy`는 초기 EXE 폴더입니다. 전체를 복사해야 하며 EXE만 옮기면 안 됩니다. 이 PC의 이전 EXE는 앱 제어 정책으로 차단되었고 0.3.0 EXE 실행 검증도 남아 있습니다. 지금은 확인된 `run_windows.bat` 소스 실행을 사용합니다.
