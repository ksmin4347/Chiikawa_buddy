검증일: 2026-11-05, 한국 시간. Windows 11 build 26200, Python 3.12.14, PySide6 6.12.0, pytest 9.2.0, ruff 0.17.3, PyInstaller 6.22.3.

## 자동 회귀

**404개 통과**: 기존 380개 + 키보드·접근성·조합 보호 검사 24개. 새 임시 DB와 Qt offscreen 플랫폼을 사용했습니다. 실제 사용자 DB는 사용하지 않았습니다. `ruff check .`, `ruff format --check .` 통과.

0.5.7의 offscreen 31개 화면 상태와 접근성 인터페이스/안내 이벤트, 실제 Windows UI Automation 읽기와 입력 중단 범위는 [5C 기록](PHASE_5C_REPORT.md)을 따릅니다. 실제 Windows 키보드·IME·스크린리더 인수는 남았습니다.

0.5.6의 수정, 100/125/150/200% Windows Qt UI 검사 116개 화면 상태와 수동 검증 한계는 [재점검 보고서](AUDIT_REPORT_0.5.6.md)에 정리했습니다. 한글 글꼴을 테스트에 등록해 offscreen의 네모 글꼴로 너비를 잘못 검사하지 않도록 했습니다.

- 기존 저장/백업·계획·반복·알림·집중/복구·통계·생활/브리핑·오프라인 채팅·말투/정보 보존·중첩 트랜잭션 회귀 유지.
- 3종 투명 프레임·상태·지연, 걱정/수면의 같은 캐릭터 기본 모습 확인.
- 폴더 밖/절대 경로·잘못된 형식·누락/손상·빈 프레임·ID/alias 오류 거부.
- 64프레임·파일/픽셀/메모리 한도·잘못된 지연·범위 밖/거대 좌표·과도한 JSON 중첩/수치 거부.
- 전환 시 집중 세션·진행 상태·위치·임시 크기·직접 숨김 보존. 기본 이름 전환과 사용자 별명 보존.
- 프레임별 타이머 간격·속도 반영, 준비/저장 실패 시 이전 그림과 선택 유지.
- 첫 선택 자동 표시·선택 저장·재시작 복원, 나중에 선택 시 데이터 유지.
- 기존 사용자에게 첫 선택 강제 없음, 0.5.1 말투를 같은 그림에 연결, 손상된 저장 팩은 모루로 복구.
- 프리셋 입력·원형/막대형 전환·우클릭 시작/일시정지·진행 중 빠른 시작 비활성화.

스키마 6을 유지하며 설정 필드만 확장했습니다. 데이터 초기화·사용자 원본 삭제·네트워크 기능 추가는 없습니다. 자동 검사가 모든 오류를 찾는 보장은 아닙니다.

- 실제 우사기 그림·원형 타이머·캐릭터 선택 중 집중 세션 유지와 캐릭터 화면 확인.

## 화면과 빌드

`tools/render_preview.py`는 전용 QA DB에서 앱 위젯만 렌더링합니다. 기존 페이지와 3종 채팅, 실제 3종 선택·집중 미리보기·첫 선택·원형 타이머, 어두운 720×560 캐릭터 화면을 점검했습니다. 사용자 데이터나 다른 앱을 캡처하지 않았습니다.

PyInstaller **0.5.7 one-folder 빌드**와 포함 파일을 확인했습니다. 모루·아이콘·고정 3종의 각 5파일(manifest/atlas/focus 3장)·완료 PCM WAV 3개·Qt Windows 플러그인·tzdata Asia/Seoul과 키보드/접근성 모듈을 포함합니다. 작업 원본·DB·로그·QA·키 파일은 제외합니다.

EXE 자체 실행은 미검증입니다. 이전 Windows 앱 제어 정책 거부를 우회하지 않았습니다. 확인된 실행 경로는 `run_windows.bat`의 Python/PySide6 소스 실행입니다.

## 0.5.4 시선·이동과 회귀

- 북쪽부터 시계 방향의 시선 방향, 대각선·경계 히스테리시스, 정지 포즈와 같은 기본 상태 갱신에서 포즈 유지.
- 직접 반응 우선·반응 종료 후 시선 복귀, 숨김·움직임 줄이기·방해 금지·집중/일시정지·수면/공백 표정 우선.
- 음수 좌표 모니터·좁은 작업 영역·좌우 경로 경계와 수평 위치 유지. 실제 장치 입력은 아닌 좌표 계산 검사.
- 이동 종료 위치 저장 1회·작은 타이머 연동, 긴 응답 공백 뒤 점프 방지와 경로 폐기.
- 집중 시작·포인터 근접·드래그·메뉴·관리창·외부 재배치·팩 전환으로 이동 취소.
- 이동 기본 off, 두 기능을 끄면 포인터 타이머 중지, 미지원 모루의 안내·설정 저장 실패 복구·앱 종료 타이머 정지.
- 기존 통계 UI 검사에서 실제 날짜와 테스트 시계가 섞여 최근 7일 범위를 벗어나던 두 실패를 재현했다. 테스트 계획 날짜와 통계 달력을 같은 가짜 시계로 맞췄다. 앱의 통계 기간 계산을 바꾼 것은 아니다. 해당 5개와 전체 회귀를 다시 확인했다.

Windows Qt 자체 검사 **48개 통과**. 0.5.3의 44개에 실제 위젯의 시선 정지·이동·집중 시 중단·종료 타이머 정지를 추가했다. 포인터와 monotonic 입력은 검사에서 주입했으며 실제 사용자 입력·절전 검증은 아니다. 클릭 인사가 끝날 시간을 기다려 반응 우선순위와 시선을 검사한다.

밝은/어두운 캐릭터 설정, 시선/달리기 미리보기, 720×560의 설정 스크롤 화면을 검토했다. 0.5.4 번들에서 3종 각 64프레임 manifest·원본과 일치하는 고정 15파일·새 동작 모듈·제품 이름/버전을 확인했다. 사용자 작업 원본은 제외하고 기존 27개를 보존했다.

실제 마우스·다중 모니터/DPI·절전·장시간 CPU/메모리와 EXE 실행은 수동 확인 대상으로 남긴다. DB 스키마는 6이며 포인터 좌표 기록·전송은 추가하지 않았다.


## 0.5.5 완료 축하·음악

- 고정 WAV 3개 형식/길이·비동기/기본음 대체 금지 플래그·멱등 중지, 허용 ID·경로·파일 크기·손상/누락/잘린 파일 거부.
- 기본 짧은 무음 축하·공연 유지와 6초 종료·음악 길이별 종료, 3종 미리보기의 기록/완료 수 미생성.
- 중복 완료 재생 방지·중단 집중 제외·휴식 무음·자동 다음 단계 지연 없음.
- 숨김/수면/방해 금지/완료 알림 off, 움직임 줄이기의 음악 단독 허용과 인사 중단.
- 소리/스타일/캐릭터 변경·누름/직접 반응·새 타이머/초기화·전원·종료 때 재생 정리.
- 긴 공백 뒤 재생 중단·음악 오류의 무음 공연 복구·완료 DB 유지·커밋 실패 때 축하 미실행.
- 설정 저장 실패 시 선택 복구와 같은 카드의 오류 표시, 진행 중 미리보기 거부 시 타이머 상태 유지.

관련 84개를 확인한 뒤 최종 수정까지 포함한 전체 366개·품질 검사를 통과했다. 사용자 DB는 사용하지 않았다. DB 스키마 6은 유지한다.

Windows Qt 자체 검사 53개 통과. 대체 오디오 백엔드로 공연/음악 미리보기·기록 미생성·중지 버튼·새 타이머 중지·종료 타이머를 확인했다. 별도로 실제 Windows 기본 재생 API에 무음 16초 WAV를 비동기로 시작하고 0.15초 뒤 중지해 호출 성공을 확인했다. 이 검사는 실제 곡의 청취·음량·장치 전환을 검증한 것은 아니다.

밝은 설정·720×560 어두운 화면의 스크롤/버튼·공연 프레임을 검토했다. 0.5.5 빌드에서 제품 이름/버전, 완료 모듈·고정 PCM WAV 3개의 원본 일치·형식/길이를 확인했다. 개발용 디코더·FLAC·작업 원본은 번들에 포함하지 않았다. 임시 압축·변환 패키지·중간 FLAC·무음 검사 파일은 정리했다.

실제 음악의 출력·음량·끝부분·장치 변경, IME/접근성·다중 DPI·절전/복귀·장시간 사용·EXE 실행은 수동 확인 대상으로 남는다.
