# PHASE 0·1 검증 기록

검증일: 2026-10-28 (한국 시간). Windows 11 build 26200, Python 3.12.14, PySide6 6.12.0, pytest 9.2.0, ruff 0.17.3, PyInstaller 6.22.3.

## 자동 회귀 테스트

`python -m pytest -q`: **34개 통과**.

- SQLite 저장/재연결, 잘못된 타입·손상 설정, 상위 스키마/손상 DB 원본 보존, 마이그레이션 전 백업.
- 저장 실패 시 UI 서비스 상태를 바꾸지 않고 오류 신호를 전달.
- 단일 화면 경계, 음수 좌표 모니터, 장치 제거 후 좌표, 모니터 사이 빈 공간, 작은/빈 화면 목록.
- 기본 PNG 프레임과 투명도, 한 번 재생 후 idle 복귀, 반복, 에셋 누락/깨진 manifest 대체, 단일 이미지, 잘못된 manifest 구조 및 루트 밖 경로 차단.
- QTest 단일 클릭 지연, 더블클릭 시 단일 반응 취소, 드래그 저장 신호와 클릭 제외.
- 숨김/움직임 줄이기 시 애니메이션 중단, 투명 속성과 빈 모서리 마스크.
- 관리창 재사용/닫기, 라이브 설정 갱신, 종료 후 설정 보존.
- 실제 자식 프로세스를 이용한 잠금·로컬 파이프 활성화·잠금 해제 후 재실행, 잠금 폴더 권한 오류 보고.

GUI 회귀 테스트는 Qt offscreen 플랫폼을 사용합니다. 이것만으로 실제 Windows 마우스 입력과 창 합성을 검증했다고 판단하지 않습니다.

`python -m ruff check .`: 통과. `python -m ruff format --check .`: 통과.

## Windows 네이티브 Qt 자체 검증

`python tools/native_smoke.py`를 Windows Qt 플랫폼으로 실행했습니다. 결과는 `.qa/native-smoke.json`에 저장됩니다.

- 플랫폼 `windows`, 연결된 화면 1개.
- 첫 화면은 캐릭터만 보이고 관리창은 숨김.
- 네이티브 트레이 아이콘의 Qt 표시 상태 true.
- 관리창 표시/닫기 후 펫 유지.
- 설정 크기 즉시 반영.
- 숨김 시 애니메이션 중단, 복원 시 재개.
- Qt 종료 경로 실행 후 설정 재조회 성공 및 실행 잠금 해제.

이는 앱 내부에서 Qt API로 검증한 결과입니다. 트레이 아이콘의 실제 위치와 사용자 클릭 성공까지 뜻하지 않습니다. 첫 일반 실행과 검증 실행은 별도 QA 데이터 폴더를 사용했습니다.

## 화면 확인

`tools/render_preview.py`로 홈·설정·어두운 홈을 앱 위젯에서 렌더링했고 한글·여백·카드·설정 배치를 시각적으로 확인했습니다. offscreen 렌더러에는 Windows의 맑은 고딕을 명시적으로 로드했습니다. 네이티브 Qt 위젯 렌더링에서도 한글 표시를 확인했습니다. 전체 바탕화면을 캡처하거나 사용자의 다른 앱 내용을 저장하지 않았습니다.

Windows 컴퓨터 조작 도구를 통한 실입력 확인은 창 선택 시 `window is not a usable app window`, 재시도 시 `window id ... was not found` 오류로 완료하지 못했습니다. 따라서 실제 클릭 통과·트레이 입력을 검증 완료로 표시하지 않습니다.

## 초기 EXE

PyInstaller one-folder 빌드가 성공했으며 캐릭터 에셋, Windows 아이콘/버전, Qt Windows 플랫폼 플러그인을 포함합니다. EXE를 소스 폴더 밖에서 실행하려 했으나 Windows가 다음 오류로 시작을 차단했습니다.

> 애플리케이션 제어 정책에서 이 파일을 차단했습니다.

이는 Windows 앱 제어 정책의 실행 거부이며 PyInstaller 빌드 실패나 자동 승인 검토 거부가 아닙니다. 정책을 변경하거나 우회하지 않았습니다. **패키징 성공 / EXE 실제 실행 검증 불가**로 기록합니다. EXE의 리소스 파일 존재 여부는 확인했지만 런타임 로드는 미검증입니다. 현재 사용 경로는 검증된 소스 실행 `run_windows.bat`입니다. PHASE 8의 전체 배포 검증은 미완료입니다.
