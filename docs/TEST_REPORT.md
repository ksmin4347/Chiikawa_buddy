# PHASE 0·1·2·3·4 검증 기록 — 0.4.0

검증일: 2026-10-30, 한국 시간. Windows 11 build 26200, Python 3.12.14, PySide6 6.12.0, python-dateutil 2.9.0.post0, tzdata 2026.5, pytest 9.2.0, ruff 0.17.3, PyInstaller 6.22.3.

**138개 통과.** 전용 임시 경로와 Qt offscreen 플랫폼을 사용했습니다. 실제 사용자 DB는 사용하지 않았습니다. `ruff check --no-cache .`와 `ruff format --check --no-cache .`도 통과했습니다.

- 기존 설정/DB 손상/상위 스키마 보호, 입력·좌표·에셋·프로세스 종료, 할 일/캘린더/분류/반복/알림 회귀 전체 유지.
- 스키마 1 및 2에서 3으로 이전, 원본 backup API 백업과 기존 할 일·설정 유지, DDL 오류 롤백.
- 가짜 monotonic/UTC 시계로 일시정지 제외, 중지한 집중 보존, 휴식 제외, 1회 완료/중복 방지, 기본 수동 다음 단계와 자동 사이클·긴 휴식·건너뛰기.
- 5초 체크포인트, 정상 종료의 마지막 진행, 강제 종료를 가정한 체크포인트 복구, 미완료 일시정지 복원과 미적립 공백, 손상 체크포인트의 고아 세션 중단.
- 절전 길이의 공백, 벽시계 앞/뒤 변경, 저장 실패 시 일시정지와 재시도, Windows 전원 이벤트 핸들러의 수동 재개 원칙.
- 자정 날짜 분리, DST 23시간 하루 배분, 일시정지 구간 분리, 분류/할 일 삭제 뒤 기록 스냅샷 보존.
- 종료 기록 분류 변경·삭제와 CASCADE 구간/누적 갱신, 진행 중 기록 삭제 금지, 100개를 넘는 완료 세션의 정확한 평균.
- UI에서 집중 시작·일시정지·재개·완료와 기록 삭제, 7/30일·8주·6개월 데이터/0일 포함 합계 일치.
- 작은 타이머 표시 모드·펫 숨김·입력 통과 플래그, 집중 중 알림 억제 선택과 완료 알림의 수동 중지/조용한 시간 준수, 모루 반응 뒤 focus/break 복귀와 움직임 줄이기.

수면 표시를 글꼴 없이 선으로 그리도록 다듬은 뒤 에셋/생활 UI 검사 16개도 다시 통과했습니다.

가짜 시계/전원 이벤트 테스트는 실제 OS 시계 변경이나 컴퓨터 절전을 수행하지 않습니다. Qt offscreen은 실제 OS 입력·합성·트레이·토스트 확인을 뜻하지 않습니다.

## Windows 네이티브 Qt 자체 검증

`tools/native_smoke.py`를 Qt `windows` 플랫폼에서 실행했습니다. 매번 `.qa/native-smoke-phase4/<고유 ID>`의 별도 DB를 만들고 `.qa/native-smoke-phase4.json`에 결과를 남깁니다.

- 처음 펫만 표시, 트레이의 Qt 표시 상태 true, 관리창 닫기 후 펫 유지.
- 크기 즉시 적용, 펫 숨김/복구와 애니메이션 중단/재개.
- 계획 입력 추가·체크 완료, 월간 렌더와 주간 7일/일간 1일 전환.
- 집중 페이지 버튼으로 시작·일시정지·재개·중지, focus 기본 상태와 작은 타이머의 Qt 표시, 통계 기록 표시.
- 생활 페이지 표시, 수동 브리핑 카드 열기/계획 이동, 집중 중 128px와 저장된 208px 분리 및 중지 시 208px 복원.
- 집중 중 전체 종료 후 미완료 체크포인트가 paused로 저장됨, 집중/생활/브리핑/알림 QTimer 정지, 설정 보존과 실행 잠금 해제.

이는 Qt API로 앱을 조작한 자체 검사입니다. 실제 마우스와 OS 트레이/알림 클릭을 대신하지 않습니다.

## 초기 EXE 빌드

0.4.0 PyInstaller one-folder 빌드와 포함 파일 확인을 수행했습니다. 기본 모루 PNG 64개·아이콘·Qt Windows 플러그인·tzdata Asia/Seoul을 포함합니다. `assets/characters` 원본 자료·사용자 DB·로그·QA 자료는 번들에서 제외했습니다.

이전 EXE 시작은 이 PC의 Windows 앱 제어 정책으로 거부되었습니다. 정책을 변경하거나 우회하지 않았습니다. 이번 EXE의 실제 실행·깨끗한 PC 검증은 수행하지 않았습니다. 확인된 실행 경로는 `run_windows.bat`의 Python/PySide6 소스 실행입니다.

## 미검증 및 수동 확인

실제 마우스/트레이, OS 완료 토스트, 실기기 절전·복귀, OS 시계 변경, 다중 모니터·DPI, Windows 10, 깨끗한 PC의 EXE, 장시간/대규모 자료 성능은 남았습니다. [MANUAL_TESTS.md](MANUAL_TESTS.md)에 항목을 유지했습니다. PHASE 5 이후와 제공 3종 캐릭터 선택/연결은 아직 구현하지 않았습니다.


생활 기능의 기본값은 주말 제외·15분 완료·3일 공백·3일 안부 간격이며 수면/자동 브리핑/전체 화면 숨김은 off입니다. 시계 보호는 관찰 가능한 불연속에 한정되며 앱 미실행 중 전진과 정상 경과는 완전히 구분할 수 없습니다. Windows 감지는 공식 알림 적합성 상태를 사용하므로 모든 전체 화면 앱의 탐지를 뜻하지 않습니다.
