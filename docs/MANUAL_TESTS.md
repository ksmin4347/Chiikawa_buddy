아래 항목은 실제 사용자 입력/장치 변경으로 확인한 뒤 체크합니다. 자동 테스트 통과를 근거로 미리 체크하지 않습니다. 별도 데이터 폴더로 실행하려면 `run_windows.bat --data-dir .qa\manual`을 사용합니다.

## 0.5.6 UI 재점검 뒤 실제 입력 확인

자동/Qt 검사 결과는 [재점검 보고서](AUDIT_REPORT_0.5.6.md)를 따릅니다. 아래 항목은 실제 입력을 완료하기 전까지 체크하지 않습니다.

- [ ] 창을 720×480 정도로 줄이고 9개 메뉴의 아래쪽 버튼까지 스크롤해 조작한다.
- [ ] 최대화 → 메뉴 이동 → 최소화 → 다시 열기에서 최대화가 유지된다.
- [ ] 긴 제목·카테고리를 만들고 툴팁, 편집 저장/취소, 월간·주간·종일 더 보기를 조작한다.
- [ ] 작은 채팅창에서 입력·확인 카드·보내기 버튼이 보이고 한글 조합 중 Enter가 의도대로 동작한다.
- [ ] Windows IME의 한/영 전환·조합 취소·한자·붙여넣기, Tab/Shift+Tab/Enter/Space와 스크린리더를 확인한다.
- [ ] 서로 다른 DPI 모니터 사이 이동·모니터 제거·작업 표시줄 위치 변경 때 창과 저장 버튼이 화면 안에 남는다.

## PHASE 1 — 현재 확인 대상

- [ ] 첫 실행에 큰 창 없이 오른쪽 아래 캐릭터와 짧은 인사가 보인다.
- [ ] 캐릭터 배경이 투명하며 빈 모서리 클릭이 뒤쪽 앱에 전달된다.
- [ ] 한 번 클릭하면 짧은 반응이 한 번 나온다.
- [ ] 더블클릭하면 관리창이 한 번만 열리고 단일 클릭 반응은 나오지 않는다.
- [ ] 드래그하면 인사 반응 없이 이동한다. 아주 작은 움직임은 클릭으로 처리된다.
- [ ] 우클릭 메뉴의 홈·인사·위치 복구·숨김·종료가 작동한다.
- [ ] 관리창을 여러 번 열어도 하나만 유지된다.
- [ ] 관리창 닫기 후 캐릭터와 트레이가 유지된다.
- [ ] 트레이 한 번 클릭은 숨기기/복원, 더블클릭은 관리창 열기로 작동한다.
- [ ] 트레이 우클릭 메뉴에서도 관리창·설정·복구·종료가 작동한다.
- [ ] 이름·크기·속도·정지 이미지·말풍선·항상 위·테마가 즉시 반영된다.
- [ ] 이름 편집 후 Enter/포커스 이동으로 저장되고 재실행 후 유지된다.
- [ ] 드래그 위치를 종료·재실행 후 복원한다.
- [ ] 시작 시 캐릭터 표시를 끄면 트레이에서 다시 표시할 수 있다.
- [ ] 같은 데이터 경로로 앱을 다시 실행하면 기존 앱만 표시하고 트레이가 늘어나지 않는다.
- [ ] 종료 메뉴 후 작업 관리자에서 해당 DesktopBuddy.exe가 남지 않는다.
- [ ] 다중 모니터의 양수/음수 좌표에 놓을 수 있다.
- [ ] 모니터 제거·해상도 변경 후 남은 화면 안에서 찾을 수 있다.
- [ ] 100%, 125%, 150%, 200% 배율 및 서로 다른 배율의 모니터 사이에서 표시/드래그가 자연스럽다.
- [ ] 절전/복귀 후 캐릭터·트레이·관리창을 다시 조작할 수 있다.
- [ ] 전체 화면 앱 중 수동 숨김과 선택형 Windows 자동 감지를 확인한다. 감지되지 않는 앱은 수동 숨김을 사용한다.
- [ ] EXE를 다른 PC로 폴더째 옮겨 실행하고 리소스와 사용자 저장 위치를 확인한다.
- [ ] EXE 교체 후 기존 설정이 유지된다. Windows 10에서도 별도로 확인한다.

- [ ] 이후/전체 수정·삭제와 취소, 반복 중단 시 개별 수정/완료 보존을 확인한다.

- [ ] 앱 알림 일시중지·자정을 넘는 조용한 시간과 재개 시 비누적을 확인한다.

## PHASE 3 — 실기기 수동 확인 대기

- [ ] 1분 집중을 실제로 기다려 1회 완료, 작은 타이머와 완료 토스트/말풍선 확인.
- [ ] 일시정지 후 1분 기다려 집중이 늘지 않음, 재개/중지와 기록 비교.
- [ ] 자동 진행 on/off, 4번째 집중의 긴 휴식, 휴식 건너뛰기 확인.
- [ ] 집중 중 Windows 절전 후 복귀: 공백 미적립, 일시정지 상태, 수동 재개.
- [ ] 시계 앞/뒤 변경: 공백 미적립과 일시정지 안내. 실제 OS 시계 변경은 자동 테스트에서 하지 않음.

- [ ] 작은 타이머 4모드, 마우스 클릭 통과, 펫 이동/숨김/모니터·배율 변경 확인.
- [ ] 기록 분류 변경·삭제와 그래프/누적/최근 날짜 갱신, 삭제 취소 시 보존.
- [ ] Windows 10, 100/125/150/200% DPI, 다중 모니터, EXE와 장시간 실행.

Qt API 자체 검증과 가짜 시계/전원 신호 단위 테스트는 실행했습니다. 위 체크는 실제 OS 입력과 하드웨어 확인이므로 자동 통과로 바꾸지 않았습니다.

- [ ] 기본 이동 off, 켠 뒤 대기·좌우 이동·끝 위치 저장과 재실행 복원.
- [ ] 가까운 포인터·드래그·메뉴·관리창·말풍선 중 이동 정지와 다시 시작 전 대기.
- [ ] 집중/일시정지·수면·방해 금지·숨김·움직임 줄이기 우선, 직접 인사 후 평소 상태 복귀.
- [ ] 실제 음수 좌표 모니터·작업 표시줄·100/125/150/200% DPI·모니터 분리·배율/크기 변경.
- [ ] 절전·복귀·UI 긴 지연 뒤 위치 점프 없음, 작은 타이머 연동·장시간 리소스 확인.

## 0.5.5 완료 축하·음악 — 실제 입력·기기 확인 대기

- [ ] 기본 짧은 무음 축하, 공연/끄기·음악 선택과 재실행 설정 복원.
- [ ] 3종 음악의 실제 스피커 출력·음량·끝부분과 27/57/16초 종료, 모루 음악 안내.
- [ ] 무음 6초 공연과 음악 연동·미리보기에서 기록/완료 수 증가 없음.
- [ ] 중복·중단 집중·휴식·자동 다음 단계에서 음악 재생 조건 확인.
- [ ] 직접 클릭/우클릭/인사·중지 버튼·새 타이머/초기화·캐릭터 변경·숨김·수면·방해 금지·절전/복귀·종료 때 재생 정리.
- [ ] 720×560·키보드/스크린리더·다중 DPI·출력 장치 변경/없음·장시간 실행과 EXE 실제 실행.

자동 검사는 대체 재생 백엔드와 임시 DB를 사용한다. 실제 Windows 비동기 재생/중지는 무음 WAV로 호출했으며 실제 음악 청취와 장치/배율 검증은 위 수동 항목이다.
