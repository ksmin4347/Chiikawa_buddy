# 캐릭터별 대화 말투 — 0.5.2

사용자가 제공한 치이카와·하치와레·우사기 말투 요청을 앱의 대화 프로필로 적용했습니다. 현재 범위는 인터넷/키 없는 오프라인 채팅과 말풍선입니다. 자유 AI 대화·코드 분석은 6단계 후속 기능입니다.

## 사용 방법

`run_windows.bat` → 첫 선택 화면 또는 캐릭터 더블클릭 → **캐릭터** 메뉴에서 선택합니다. **채팅** 오른쪽 위 목록으로도 그림과 말투를 함께 바꿀 수 있습니다. 선택은 다음 실행에도 유지합니다. 기존 모루 설정과 사용자 별명을 보존하며, 0.5.1의 대화 선택이 있으면 같은 캐릭터 그림을 연결합니다. [그림·상태 안내](CHARACTER_GUIDE.md)를 확인하세요.

지원 예시:

- `안녕!` / `오늘 공부하기 싫어.` / `나 오늘 시험 잘 봤어!`
- `오늘 계획 다 못 지켰어.` / `나 좀 응원해 줘.` / `고마워!`
- `오늘 할 일 보여줘` / `오늘 얼마나 공부했어?` / `내 상태 알려줘`
- `할 일 추가: 자료구조 복습` / `25분 집중 시작` / `타이머 일시정지`

짧은 대화는 알려진 문장을 분류하고 상황별 문구를 고릅니다. 응원을 요청했다고 타이머나 할 일을 임의로 시작/등록하지 않습니다. 이해하지 못한 문장은 해당 캐릭터의 안내와 지원 예시를 표시하고 입력을 유지합니다.

## 공통 규칙

- 현재 선택한 캐릭터만 새 답변에 적용합니다. 다른 캐릭터의 감탄사를 섞지 않습니다.
- 세 캐릭터는 친근한 반말을 사용합니다. 말투를 적용했다는 메타 설명을 대화에 덧붙이지 않습니다.
- 캐릭터/상황별 문구를 순환하며 기쁨·걱정·응원·선택·확인·성공·오류 표현을 구분합니다. 임의의 응답 지연을 넣지 않습니다.
- 조회 결과와 실제 실행 여부가 우선입니다. 미리보기에는 실행 전임을 알리고 실제 커밋 뒤에 성공을 표시합니다.
- 데이터와 문구를 분리합니다. 제목·날짜·시간·분류·코드·경로·명령어·수식을 전역 문자열 치환으로 바꾸지 않습니다. 사용자 데이터의 괄호·감탄사도 그대로 보존합니다.
- 실패나 공부 공백을 이유로 모욕하거나 죄책감을 주지 않습니다. 사용자가 말하지 않은 공부 이력·성공 원인을 지어내지 않습니다.

## 치이카와

소심하고 수줍으며 감정이 풍부하지만 항상 울거나 겁먹은 상태로 표현하지 않습니다. 짧은 감탄사와 머뭇거림, 조심스러운 응원을 사용합니다. 기쁠 때는 밝게 반응합니다. 긴 정보는 짧은 문장과 원문 정보 줄로 나눕니다. 유창하고 자신감 넘치는 긴 독백이나 같은 감탄사의 억지 반복을 피합니다.

예: `아…! 왔구나…! 헤헤…!`, `응…! 네 속도로… 같이 해보자…! 응원할게…!`

## 하치와레

밝고 긍정적이며 다정한 친구의 반말입니다. 어려움에 공감한 뒤 작은 해결책을 제시하고 호기심과 순수한 감탄을 표현합니다. 상황을 정리할 때 `~라는 거지?!`를 활용하되 모든 문장에 반복하지 않습니다. 과장된 애교나 근거 없는 낙관적 확언을 피합니다.

예: `왔구나! 오늘도 같이 해보자!`, `이렇게 바꾼다는 거지?! 아직 실행 전이니까 내용을 확인해줘!`

## 우사기

자유롭고 장난스러우며 활기찬 반말입니다. 짧고 직설적으로 말하고, 실패를 비난하기보다 가볍게 다시 해보도록 응원합니다. 실제 정보는 다음 형식 안에서 전달합니다.

**감탄사 + (실제 대화 내용과 정보)**

- 반가움: `야하!!`, `이야하아!!`
- 행동 개시/동의: `우라!`, `우라라라!!`
- 장난/감사: `푸루야!`, `푸루루루~`
- 의문/확인: `하아?!`, `후웅~`
- 성취/기쁨: `우라야하!!`

상황별 후보를 순환하며 하나의 감탄사에 의미를 고정하지 않습니다. 괄호 밖에는 일반 대화 문장을 쓰지 않습니다. 괄호 안은 감탄사의 기계적 번역이 아닌, 우사기가 말한다면 할 법한 짧고 유쾌한 내용입니다. 지나치게 정중하거나 사무적인 문장을 피합니다. UI 버튼·메시지 화자/시각 같은 메타데이터는 대화 본문과 구분합니다.

예: `우라! (타이머 출발! 가보자! 집중 · 25분)`

## 적용 범위와 저장

오프라인 채팅의 인사·짧은 대화·조회·선택·변경 확인·실행 결과·취소·오류와 캐릭터 클릭/초기 인사·집중/휴식 완료·할 일 완료·공부 공백 말풍선에 적용합니다. 설정/통계 표·브리핑의 사실 카드와 메뉴는 읽기 쉬운 일반 UI 문구를 유지합니다.

말투 전환은 확인 대기 카드를 취소하며, 진행 중 타이머와 공부 기록은 유지합니다. 이전 메시지의 내용과 당시 캐릭터를 바꾸지 않습니다. 메시지에는 캐릭터 ID와 프로필 버전을 저장하며, 스키마 5 이전 메시지는 원문을 유지한 채 기본 모루로 분류합니다. DB 이전 전에 원본 백업을 만듭니다.

보관 off일 때는 메시지와 화자 정보가 함께 메모리 최대 200개에만 남습니다. 저장 중 오류에는 변경과 성공 대화가 함께 롤백됩니다. 성공 커밋 뒤 다른 설정 신호로 캐릭터가 바뀌어도 이미 작성한 답변을 다른 캐릭터로 표시하지 않습니다.

## 후속 AI 연결 계약

6단계에서 AI를 연결할 때에도 선택한 프로필, 위 말투 규칙, 짧은 예시와 정보 보존 규칙을 응답 지침으로 전달합니다. 말투 지침은 실행 권한을 바꾸지 않습니다. AI가 제안한 변경은 동일한 검증/확인/중복 방지 경로를 거치고 실제 실행 결과를 근거로 답해야 합니다. 현재 이 앱에는 온라인 AI 요청 경로가 없습니다.

## 검증

0.5.1의 말투/감정·기술 원문·기존 화자·저장 실패·스키마 이전 검사를 유지하고, 0.5.2의 실제 팩·선택·타이머 사용성 검사를 더해 전체 284개를 통과했습니다. 품질·밝은/어두운/720×560 화면·Windows Qt 자체 실행·빌드를 확인했습니다. 실제 한글 IME·스크린리더·DPI·Windows 10·EXE 실행은 [수동 검사](MANUAL_TESTS.md)에 남아 있습니다.
